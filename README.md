# Random Image Generator

Random Image Generator is a simple web project that displays random images using the Picsum Photos API.

## Features

- Generates a random image
- Generate button to change the image
- Responsive design
- Simple and clean user interface
- Works on desktop and mobile devices

## Technologies Used

- HTML
- CSS
- JavaScript

## API Used

https://picsum.photos/200/300

## How It Works

When the user clicks the Generate button, JavaScript requests a new random image from the Picsum Photos API.
